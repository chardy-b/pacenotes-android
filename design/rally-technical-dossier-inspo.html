Dossier

An original navigation instrument built from disciplined technical drafting, nocturnal mountain-road atmosphere, and restrained analog racing energy.

SurfaceMonitor — real-time route state is the composition, not a marketing page.
Driving ruleSeverity, direction, and distance must be readable before any visual flavor is noticed.
Reference postureTechnical, urgent, mechanical. Never franchise imitation; no marks, characters, screenshots, or copied screens.
01 /

Image language

Use roads and mechanical diagrams as atmosphere. The active screen stays quieter than this board; grain and scan texture are for pre-drive, replay, and recap.

02 /

Color & type

Cyan describes position and route continuity. Red is an active signal, not a decoration. Paper carries instructions.

Primary posture: dark, precise, and angular. Use color as an operational vocabulary rather than a theme wash.

Display type is compressed and forceful for curve calls. Monospace appears in labels and system metadata only—never for long reading.

Starter CSS

These tokens and components are ready to transfer into the Compose theme as semantic color/type/spacing equivalents.

Active navigation: no scanline overlay, animated grain, or diagnostic density over the moving map.
Accessibility: never color-only. Direction is arrow + word/voice, and key text survives 200% font scale.
Motion: only 150–200 ms state transitions; respect reduced motion. Replay may be more expressive.
Originality: retain the industrial/racing posture; never introduce franchise symbols or copied screen structure.
:root {
  --void: #0b0d0e;
  --graphite: #151a1b;
  --paper: #f1f4ed;
  --signal-red: #e2493d;
  --telemetry-cyan: #63d4d0;
  --grid: #405052;
}
